## Problem Statement and Objective
This project serves as an educational framework for mastering the fundamental workflows of Machine Learning using Python. The primary objective is to demonstrate proficiency in data manipulation and exploratory data analysis (EDA) using **NumPy** and **Pandas**, while emphasizing the critical importance of **reproducibility** in experimental results through controlled seeding.

## Dataset Status
Currently, the project utilizes **synthetic datasets** specifically designed for laboratory exercises and initial statistical exploration. These datasets simulate student performance metrics to validate data processing logic. As the project evolves, transition to a comprehensive, real-world dataset is planned for advanced model implementation.

## Project Execution Guide

### 1. Environment Setup
Clone the repository to your local environment:
```bash
git clone https://github.com/your-username/ML-Project-Yacin-Arafat-160.git
cd ML-Project-Yacin-Arafat-160
```

### 2. Dependency Management
It is recommended to use a virtual environment. Install the necessary libraries using the provided requirements file:
```bash
pip install -r requirements.txt
```
*Required libraries include: NumPy, Pandas, Matplotlib, and Jupyter.*

### 3. Running the Notebooks
Execute the following command to launch the Jupyter environment:
```bash
jupyter notebook Notebooks/lab01.ipynb
```
*Note: The notebooks are also compatible with Google Colab for cloud-based execution.*
